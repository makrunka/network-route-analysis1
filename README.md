# Network Route Analysis

Веб-інструмент для аналізу маршрутів передачі даних у корпоративній мережі.

## Функціонал
- граф із 30+ вузлів
- алгоритм Дейкстри
- резервні маршрути
- симуляція відмов вузлів
- пошук критичних вузлів
- тестування мережі

## Запуск
```bash
pip install -r requirements.txt
python -m streamlit run app.py
